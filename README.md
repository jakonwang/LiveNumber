# 直播扣号打单 v0.6.2

监听 TikTok 直播弹幕，命中规则（如纯数字 1-200）后分配客户编号，用标签打印机自动打印。

## 安装

运行 `dist\LiveNumber-Setup-<版本>.exe`，按提示安装（可选安装位置），桌面会有「LiveNumber 直播扣号打单」快捷方式。
数据保存在 `%APPDATA%\livenumber\`，卸载、重装、升级都不会删除。

> 安装包没有代码签名，第一次运行 Windows 可能提示「已保护你的电脑」：点「更多信息 → 仍要运行」。

## 开发运行

```powershell
npm install
npm start
```

或双击 `start.bat`。打包安装程序：`npm run dist`（输出到 `dist\`）。

标志：`src/assets/logo.svg`（标准版）和 `logo-small.svg`（16–32px 粗线版）。改了之后运行 `npx electron build/make-icon.js` 重新生成 `build/icon.ico`、`src/assets/icon.ico` 和预览图 `build/logo/preview.png`。

## 开播前

「系统设置 → 环境自检」点一下：检查打印机、模板、能否访问 TikTok 和签名服务、浏览器模式是否已登录、共享主机、监控规则。

## 用法

1. 右上角填主播用户名（或直播链接），点「连接」。
2. 「打印设置」里选择打印机（如 Deli DL-720C），点「设置模板」调整标签，再点「打印测试」。
3. 「监控限制」设置要扣的号码范围；「抢单」设置每个号码在 N 秒内限几人。
4. 没开播时可以在「弹幕信息」里用「模拟弹幕」测试整套流程。

## 多语言 / 多国家（v0.8）

- **界面语言**：中文、Tiếng Việt、English、ไทย、Bahasa Indonesia、Bahasa Melayu。左下角下拉框或「系统设置 → 语言与地区」切换，界面刷新一下即可，正在进行的直播连接和打印不受影响。运行日志、托盘菜单、悬浮大屏（含 OBS 浏览器源）、A4 发货汇总、导出表格的表头都跟着变。
- **国家 / 站点**：越南、泰国、印尼、马来西亚、菲律宾、新加坡。切换后自动改：TikTok Shop 卖家中心域名（seller-xx.tiktok.com）、金额格式（120.000 / 120,000）、弹幕取消关键词，并可顺便把界面语言改成当地语言。
- 还是默认文字的设置（大屏标题、空闲提示、新人标识、语音播报、默认模板名、发货单「共…件」）切换语言时自动换成新语言；自己改过的不动。
- 导入表格时，表头用任何一种语言都能识别（如越南语导出的客户编号表可以直接导入）。

**开发：加新的界面文字** —— 用 `$t('中文原文')` 包起来（参数写 `$t('编号 {0} 已重打', code)`），然后：

```
node build/i18n/extract.js --missing vi   # 列出缺翻译的 key
```

把翻译加到 `src/i18n/locales/<语言>.json`。`npm test` 会检查 5 种语言是否齐全、占位符是否一致。

## 订单备注（TikTok Shop，v0.7）

左侧「订单备注」。把扣号信息写进 TikTok Shop 待发货订单的「卖家备注」，打包时看备注就知道是哪个客户、几号。

- **登录店铺**：「浏览器登录」打开卖家中心登录页，登录成功自动关闭；或「Cookie 登录」，粘贴 Cookie-Editor 等插件导出的 JSON（也支持 `a=1; b=2`）。登录信息只存在本机。
- **读取订单**：先选订单状态（待发货 / 待揽收 / 已发货（待收货）），忘记备注的订单发货后也能补写。列出订单号、下单时间、金额、商品、买家，以及匹配到的扣号和将要写入的备注。
- **怎么匹配**：卖家中心只给打码的买家用户名（如 `p*********5`：首字母、尾字母、长度）。软件拿这个格式去「客户编号」里找客户（先比用户名，对不上再比昵称），得到客户编号：
  - 客户表里多个客户都对得上 → 用下单时间窗内扣过号的那一个；还定不了就标「多人对得上」，不自动写，可手动「订单备注」。
  - 时间窗内的扣号记录用来补流水序号、弹幕等字段。向前回溯 N 分钟：先扣号、后下单（默认 5）；向后回溯 N 分钟：先下单、后扣号（默认 0）。
- **备注模板**：默认 `【{fixedno}】{accname}` → `【1271】buyer_demo`。字段：用户名、昵称、客户编号、流水序号、主播备注、弹幕信息、订单编号、下单时间、订单金额、分拣号（带前缀的编号）。
- **选项**：完全覆盖 / 追加；合并订单（同一买家的多张订单写同一条备注）；流水策略（全部 / 最早 / 最新）；同一条扣号能否用于多张订单；跳过已有别人备注的订单；请求间隔。
- **批量备注 / 备注选中 / 单条订单备注**，日志里逐条显示「订单【…】备注成功，内容：【…】」和汇总。
- **自动备注**：每 N 秒读一次最近 N 小时的新订单，只写匹配上、还没写过的。

## 场次与发货（v0.5）

- **场次**：每场直播一个场次。控制台顶部「开始新场次」（可选流水归零），第一单进来时也会自动开场。打印历史、发货汇总都能按场次筛选。
- **发货汇总（对照表）**：左侧「发货汇总」，按客户合并本场订单——编号、客户、商品明细（同款 ×N）、件数、合计金额。
  - 导出 Excel（CSV）、导出 PDF、打印 A4（带「已配」勾选栏，打包时对照）
  - 打印发货单：每位客户一张标签，默认用自带的「发货单(40*30)」模板（编号、昵称、商品清单、件数、合计），也可以在模板设计里用「商品清单 / 件数 / 合计金额」组件自己做。
- **弹幕取消订单**：买家发「hủy」取消自己最近一单，「hủy 15」取消 15 号（关键词可改，默认 120 分钟内）。库存退回，抢单名额让给下一个人，大屏上移除。打印历史里也能手动「取消 / 恢复」。已取消的订单不计入统计和发货汇总。
- **号码计价**：商品信息页勾选「没有对应商品时按号码计价」，金额 = 号码 × 倍数（如 150 × 1000 = 150.000），用于销售额统计和发货汇总。

## 悬浮大屏（v0.4）

顶部栏点「大屏」或按 F8 打开。给主播看，也可以放进直播画面给观众看。

- **抢单**：正在被抢的号码、已抢人数 / 限额、倒计时圆环（最后 5 秒变红），抢满显示「已抢完」。
- **竞拍**：当前最高价（出价时跳动）、领先者、倒计时、出价次数；成交后显示 6 秒「成交」横幅。
- **最新下单**：编号 + 昵称 + 号码 / 商品，新客户标「新」。
- **风格**：深色玻璃 / 绿幕（直播软件里用色度键抠掉绿色）/ 透明；可调字体大小、窗口透明度、置顶。
- **昵称打码**：默认开启，Nguyễn Thị Hoa → Ng***，保护买家隐私。
- **OBS / TikTok 直播伴侣**：系统设置 → 悬浮大屏 → 打开「浏览器源」，把地址（默认 `http://127.0.0.1:18630/`）添加为浏览器源，宽 420、高 640。只在本机监听，局域网其他电脑访问不到。

窗口可以拖动标题栏移动、拖边缘调整大小，位置会记住。

## 第三版新增

- **全新界面**：侧边栏导航 + 深色/浅色主题（深海蓝底、青绿渐变强调色），窗口标题栏跟随主题。
- **直播控制台**：今日订单/买家/销售额/打印队列卡片、「最新命中」卡片流（新客户标「新」）、弹幕流、运行日志。
- **商品信息**：弹幕号码 = 商品编号时，自动把商品名称、价格、规格印到标签，扣减库存；可设「只打印有商品的号码」「售罄不打印」。支持 CSV 导入导出（表头：商品编号, 商品名称, 价格, 库存, 规格）。
- **数据统计**：今天/昨天/近 7 天/近 30 天/自定义，订单、买家、新客户、销售额、客单价、每小时订单柱状图、买家排行、热门号码。
- **名单管理**：黑名单 / 白名单两种模式（白名单模式下只打印名单里的人），支持 CSV 导入导出。
- **新人标识**：第一次下单的客户在标签「新人」组件上印「新」（文字可改）。
- **命中提醒**：提示音、语音播报（如「45号 15」，内容可自定义）。
- **打印失败自动重试**、**数据备份/恢复**。
- 模板设计器新增组件：商品名称、商品价格、商品规格、新人；文字组件可加边框。

## 第二版新增

- **拖放模板设计器**（打印设置 → 设置模板）：文本、客户编号、用户名、昵称、弹幕信息、日期、流水、主播备注、竞拍金额、条形码、二维码、图片、横线、竖线、矩形、椭圆。拖动移动，右下角蓝点缩放，方向键微调；可建多个模板，导入/导出 JSON。
- **竞拍模式**：倒计时内收出价（支持 `150k` = 150000），只接受比当前最高价高出「加价」的出价；时间到自动打印最高出价者。可选出价自动开始或手动开始、最后 N 秒出价延时、立即成交、取消本轮。
- **编号生成**：递增 / 补缺（删掉的编号重新分配，从最小空号开始）/ 共享。
- **局域网共享编号**：一台电脑在「高级设置」开启「本机作为主机」，其他电脑「编号生成」选「共享」并填主机地址，多台电脑编号不会重复。主机连不上时这条记为失败，可在打印历史里「重打」重新申请编号。
- **浏览器模式**：右上角选「浏览器模式」再连接，会打开一个内置浏览器窗口进入直播间（可在里面登录 TikTok，登录会保存），直接从页面里抓弹幕，不依赖第三方签名服务。这个窗口要保持打开，可以最小化。

## 说明

- 弹幕来自开源库 tiktok-live-connector（非官方接口），依赖第三方签名服务 Euler Stream。连接频繁失败时，在「高级设置」填写 API Key。
- 数据目录 `%APPDATA%\livenumber\`：
  - `data\data.json`：设置、模板、客户编号、商品、名单、场次（小文件）
  - `data\history.jsonl`：打印历史，每单追加一行（断电最多丢最后一行，启动时自动整理）。旧版数据第一次启动时自动迁移
  - `logs\YYYY-MM-DD.log`：运行日志，每天一个，保留 14 天（系统设置 → 数据 → 打开运行日志）
- 点窗口关闭按钮会**最小化到托盘**（任务栏右下角），继续收弹幕和打印。单击托盘图标打开窗口；右键菜单可看直播状态、开关悬浮大屏、暂停/开启打印、退出。连接直播时退出会二次确认。想改成直接退出：系统设置 → 直播连接 → 关闭窗口时。
- **客户编号导入**（客户编号页 → 导入）：支持 Excel（.xlsx / .xls）和 CSV（UTF-8 或中文 Excel 的 GBK 编码）。第一行表头需要「用户名」和「编号」，「昵称」可选；也认「账号 / 客户编号 / username / code」等写法。编号里的序号头会去掉（A123 → 123）。可选「用表里的编号覆盖」或「保留现有，只加新客户」；导入后会提示重复编号，「下一个编号」自动排到最大编号之后。商品和名单的导入也支持 Excel。
- 只能同时开一个程序；重复打开会切回已经开着的窗口。
- 程序内部出错只记日志、不退出；界面崩溃会自动重新加载，打单和打印不中断。
- 断线重连间隔逐步拉长：10、20、40、80、160 秒，最长 5 分钟；连上后重置。
- 语音播报高峰时只念最新的一单，不会积压。
- 纯数字识别 `15`、`#15`、`15.`、`15!!`、`15 15`。
- 重复下单（同一人同一号码，系统设置 → 命中提醒）：默认 60 秒内重复发只算一单；可改为「同一场只算一单」或「每条都算（可买多件）」。
- 开启共享编号主机时如果没填密码，会自动生成一个（日志里会显示），其他电脑要填同样的密码。
- 同一用户名永远对应同一个客户编号；新用户按递增分配。
